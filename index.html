Ajouter ou modifier un créateur

Crée d’abord, dans App Store Connect (Abonnements › Codes d’offre), une offre à part pour ce créateur, dont le nom de référence est exactement son code (ex. EMILIE), puis ajoute-le ici avec le même nom. Apple ne transmet que le nom de l’offre : un code rangé dans une offre partagée ne serait pas compté pour le créateur. Pour modifier : clique sur le code dans le tableau.
